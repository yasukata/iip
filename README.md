# iip: an integratable TCP/IP stack

iip is a formally-verifiable, fast and portable TCP/IP stack.

The entire codebase of iip is [formally verifiable](#formal-verification-with-frama-c) with Frama-C and its Weakest Precondition (WP) plugin.

iip [complies with C89/C++98](#compilation-test) so that it can be compiled and used for a wide range of platforms and use cases.

**WARNING: The authors will not bear any responsibility if the implementations, provided by the authors, cause any problems.**

## other building blocks

### I/O subsystem
- [iip-dpdk](https://github.com/yasukata/iip-dpdk): a DPDK-based backend (Linux); [how to use](https://github.com/yasukata/bench-iip#build).
- [iip-af_xdp](https://github.com/yasukata/iip-af_xdp): an AF_XDP-based backend (Linux); [how to use](https://github.com/yasukata/bench-iip#af_xdp-based-backend).
- [iip-netmap](https://github.com/yasukata/iip-netmap): a netmap-based backend (FreeBSD or Linux); [how to use](https://github.com/yasukata/bench-iip#netmap-based-backend).

### example application
- [bench-iip](https://github.com/yasukata/bench-iip): a benchmark tool.
- [mimicached](https://github.com/yasukata/mimicached): a memcached-compatible cache server.

### simulation
- [iip-ns](https://github.com/yasukata/iip-ns): a helper for running iip on the ns-3 simulator (Linux).

### test
- [ai-test-iip](https://github.com/yasukata/ai-test-iip): a fully AI-generated test suite for iip.

## formal verification with Frama-C

This section describes how to use Frama-C to formally verify iip. The current focus is on the runtime error (RTE) checks generated by the RTE plugin activated with the ```-wp-rte``` option. These checks help identify potential issues such as invalid memory access and arithmetic overflow.

Please make a directory named ```frama-c``` and enter it with the following commands.

```
mkdir frama-c
```

```
cd frama-c
```

Please save the following C programs as ```iosub.c``` and ```main.c``` in the ```frama-c``` directory.

#define false 0

#include "./iosub.c"

#define IIP_OPS_ARP_ETHERNET_REPLY() do { iip_ret_int = rx_pkt % 2 ? 1 : 0; } while (0)
#define IIP_OPS_UDP_PAYLOAD() do { iip_ret_int = pb_id % 3 ? 1 : 0; } while (0)
#define IIP_OPS_TCP_ACCEPT() do { iip_ret_bool = pb_id % 4 ? true : false; } while (0)
#define IIP_OPS_TCP_CONNECTED() do { iip_ret_int = conn_id % 5 ? 1 : 0; if (conn_id) { II_TCP_CONN(conn_id).flags |= II_TCP_CONN_FLAGS_ACK_PUSHED; } } while (0)
#define IIP_OPS_TCP_ACCEPTED() do { iip_ret_int = conn_id % 6 ? 1 : 0; if (conn_id) { II_TCP_CONN(conn_id).flags |= II_TCP_CONN_FLAGS_ACK_PUSHED; } } while (0)
#define IIP_OPS_TCP_URGENT() do { iip_ret_int = (conn_id % 7 ? 1 : 0); } while (0)
#define IIP_OPS_TCP_FASTOPEN_REQUEST() do { iip_ret_int = (conn_id % 8 ? 1 : 0); } while (0)
#define IIP_OPS_TCP_PAYLOAD() do { iip_ret_int = (conn_id % 9 ? 1 : 0); } while (0)
#define IIP_OPS_TCP_STATE_CLOSE_WAIT() do { iip_ret_int = (conn_id % 10 ? 1 : 0); { II_TCP_CONN(conn_id).flags |= II_TCP_CONN_FLAGS_ACK_PUSHED; } } while (0)
#define IIP_OPS_TCP_CLOSED() do { iip_ret_int = (conn_id % 11 ? 1 : 0); } while (0)
#define IIP_OPS_TCP_IPV4_FASTOPEN_CHECK() do { iip_ret_bool = (conn_id % 12 ? 1 : 0); } while (0)
#define IIP_OPS_TCP_IP_NEGATIVE_ADVICE() do { iip_ret_int = (conn_id % 13 ? 1 : 0); } while (0)
#define IIP_OPS_IPV4_OPT_SEND() do { if (dst_ipv4_be) { ipv4_opt_len = 4; ipv4_opt[0] = 0; ipv4_opt[1] = 1; ipv4_opt[2] = 2; ipv4_opt[3] = 3; } } while (0)
#define IIP_OPS_IPV4_TCP_INPUT_FILTER() do { if (pb_id % 2) iip_ret_bool = true; else iip_ret_bool = false;  } while (0)
#define IIP_OPS_UDP_ACCEPT() do { iip_ret_bool = pb_id % 4 ? true : false; } while (0)

#define SKIP_IIP_DEFINITION
#include "../main.c"
#undef SKIP_IIP_DEFINITION

	assigns \nothing;

int main(void)

The following command attempts verification for the entire iip TCP/IP stack implementation. This may take several hours. Note that the ```-wp-print``` option shows many details, therefore, we recommend redirecting it to a file.

```
frama-c -cpp-extra-args=-CC -wp-prover alt-ergo,cvc4,cvc5,z3 -wp -wp-rte -wp-smoke-tests -wp-print main.c
```

We can attempt the verification for a particular function specified through the ```-wp-fct``` option. This may complete in a few seconds. The following is an example command that performs the verification only for ```iip_run``` (without ```-wp-print```).

```
frama-c -cpp-extra-args=-D_ENABLE_FRAMA_C_CHECK,-CC -wp-prover alt-ergo,cvc4,cvc5,z3 -wp -wp-rte -wp-smoke-tests main.c -wp-fct iip_run
```

## compilation test

This section describes how to check if iip complies with C89/C++98.

Please first create a directory named ```compilation``` and enter it.

```
mkdir compilation
```

```
cd compilation
```

Please save the code below as a file named ```main.c``` in the directory ```compilation```.

<details>

<summary>please click here to show main.c</summary>

```c
typedef char           int8_t;
typedef short          int16_t;
typedef int            int32_t;
typedef long           int64_t;
typedef unsigned char  uint8_t;
typedef unsigned short uint16_t;
typedef unsigned int   uint32_t;
typedef unsigned long  uint64_t;

typedef unsigned long  uintptr_t;

#define UINT16_MAX 0xffff
#define UINT32_MAX 0xffffffff

#define bool int
#define true 1
#define false 0

#define IIP_TCP_OPAQUE_P uintptr_t

#define IIP_PKT_P uint32_t
#define IIP_OPAQUE_P uint32_t

#define IIP_TCP_CONN_STRUCT_EXTRA int data

#include "../main.c"

void _start(void) {
	(void) iip_run;
	(void) iip_arp_ethernet_request;
	(void) iip_tcp_rxbuf_consumed;
	(void) iip_tcp_ipv4_ethernet_connect;
	(void) iip_tcp_close;
	(void) iip_tcp_send;
}
```

</details>

The following commands will produce ```a.out```.

```
gcc -Werror -Wextra -Wall -pedantic -std=c89 -nostartfiles -nodefaultlibs -nostdlib -nostdinc main.c
```

```
g++ -Werror -Wextra -Wall -pedantic -std=c++98 -nostartfiles -nodefaultlibs -nostdlib -nostdinc main.c
```

Note that the program above is just for checking whether ```main.c``` can be compiled or not, and the generated binary ```a.out``` is not runnable.
